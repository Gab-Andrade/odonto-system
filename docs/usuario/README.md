# Guia do Odonto System

O Odonto System é um sistema de gestão para clínicas odontológicas, feito para ser usado no computador e no tablet, inclusive na cadeira de atendimento.

Este guia explica, em linguagem simples, o que cada parte do sistema faz e quem pode usá-la. Ele cresce à medida que novas partes ficam prontas.

> O sistema está em construção. Hoje estão prontas as bases de acesso e segurança, e as telas ainda estão sendo desenvolvidas.

## Partes do sistema

| Parte | Para que serve |
|---|---|
| [Acesso e login](identidade.md) | Entrar no sistema, escolher a clínica e entender os perfis de acesso |
| [Estoque de materiais](estoque.md) | Cadastrar os materiais da clínica, com unidade de uso e custo, e desativar os que não são mais usados |
| [Histórico de ações](auditoria.md) | Ver quem fez o quê e quando, para segurança e para a LGPD |
| [Tabelas de preço](precificacao.md) | Montar os preços da clínica por planilha ou por fórmula de custos, definir a quem cada tabela se aplica e consultar ou congelar o preço de um procedimento |

## Perfis de acesso

| Perfil | Quem é |
|---|---|
| Administrador | Responsável pelo sistema na clínica |
| Gestor | Cuida da gestão do consultório |
| Dentista | Atende os pacientes |
| ASB | Auxiliar de saúde bucal |
| Recepção | Atendimento, agenda e cadastro |

## Privacidade

Cada clínica só vê os próprios dados, mesmo que várias clínicas usem o mesmo sistema. As ações importantes ficam registradas e não podem ser apagadas.
